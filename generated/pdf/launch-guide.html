Launch Guide

The Money Map

Navigate Your Journey to Financial Freedom

A local-first atlas of personal finance — 92 maps, a doubloon economy, and a voyage certificate. This guide gets it running in minutes.

What you are launching

The Money Map is a Next.js application where Markdown is the source of truth. Ninety-two infographics have been extracted into structured, searchable content that renders as an interactive website — and powers a flipbook, PDF, and search index from one source.

Gamified: reading a map earns doubloons; filling a chapter chest pays a bounty; charting all 92 mints your certificate.
Themed: a black / white / green design system with gold reserved for treasure, in Garamond throughout.

Requirements

  • Node.js 20+ — check with node -v
  • npm (ships with Node)
  • A modern browser (Chrome, Safari, Firefox, or Edge)

Launch in three commands

cd The-Money-Map
npm install
npm run dev

Then open http://localhost:3000. That's the whole voyage — the content pipeline builds automatically as the dev server starts.

Everyday commands

npm run dev        # develop (content watch + Next dev server)
npm run build      # production build (static, 108 pages)
npm run start      # serve the production build
npm run generate   # rebuild content JSON + search + treasure manifest
npm run audit:provenance   # verify figures + table integrity
npm run pdf        # regenerate the guide + e-book PDFs
npm run flipbook   # regenerate the guide + e-book flipbooks

Adding or editing a map

Every lesson is one Markdown file at content/chapters/<chapter>/<lesson>.mdx. Frontmatter holds the typed content blocks; the body is short framing prose. After editing:

npx velite --clean   # validate — the build fails closed on any error

No code change is needed to add content unless you introduce a new block type.

Deploying

  1. Run npm run build — output is fully static.
  2. Deploy the app to any Node host (Vercel, Netlify, a container), or export static HTML.
  3. Progress, bookmarks, and doubloons live in the browser (local-first) — no server or database required.

Where things live

  • content/ — the source of truth (Markdown maps)
  • components/ — blocks, reader, treasure, and pirate art
  • scripts/ — search index, provenance audit, PDF + flipbook generators
  • memory/ — the project knowledge base (load these first)
  • generated/ — disposable build output (never hand-edit)

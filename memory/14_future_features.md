# 14 · Future Features

Ordered. Each gets its own spec before any code. Do not build ahead.

## Milestone 2 — Flipbook
CSS 3D page-turn reader. See [11_flipbook](11_flipbook.md).

## Milestone 3 — PDF + print
Print-CSS + headless Chromium. See [10_pdf_generation](10_pdf_generation.md).

## Milestone 4 — Calculators (12)
Compound interest, retirement, mortgage, debt payoff, savings rate, FIRE,
budget, net worth, withdrawal, inflation, asset allocation, investment. Each is
a typed, pure calculation module + a component; they compute, never recommend
(see [05_finance_rules](05_finance_rules.md)). Embeddable in lessons as a new
`calculator` block type.

## Milestone 5 — Gamification, then SaaS
- Islands unlock as chapters complete; badges; financial XP; the treasure-map
  progress view. Gold is the reward currency (see [02_brand](02_brand.md)).
- Only then: accounts, cloud sync, the `useProgress` shape already anticipates
  this. Newsletter, premium, Plaid/Stripe are further out and unscoped.

## Deliberately not doing (YAGNI)
No AI tutor, brokerage integrations, or community until the reading experience
and calculators are excellent. A great atlas first.

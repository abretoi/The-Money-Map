# 03 · UI

## Typography

**Garamond everywhere** — one `--font-garamond` stack drives both `--font-sans`
and `--font-serif` (`styles/tokens.css`). Do not reintroduce a separate sans.

## Imagery

Pirate/cartographic identity is bold and apparent, not just texture. Small
glyphs in `components/art/Icons.tsx`; large motifs (ship, lighthouse, crest,
cannon, swords, gold, rum, jewel, hat, flag, wheel, treasure map) in
`components/art/Pirate.tsx`. Compose with `PirateFrieze` (section dividers) and
`PirateBackdrop` (large faint per-page motif) from `PirateScene.tsx`. Gold tint
is correct — these are cartographic/treasure vocabulary (see [02_brand](02_brand.md)).

**Do not place decorative art over the sidebar outline** — a compass watermark
once overlapped the chapter titles. Backdrops on content pages use
`overflow-hidden` containers and low opacity so they never obscure text.

## Layout

Three panels, collapsing to one on mobile:
- **Left** — chapter/lesson outline, utility links, and the *Your Voyage* menu
  (save / load / reset progress via `ProgressControls`). Mobile: drawer.
- **Centre** — prose and rendered blocks. Measure capped at 68ch. The home hero
  spans the full page at `--text-display`.
- **Top bar** — doubloon counter, a gold Save chip, search, theme.

Hover: cards and `.hover-gradient` rows reveal a green→white→black gradient.

## Non-negotiables

1. **Surface ladder** — four discrete elevations, hairlines at `--line-1` /
   `--line-2`. Never invent a fifth surface.
2. **8pt grid** — spacing comes from `--s-1`…`--s-10`. Never `padding: 13px`.
3. **Card hover** — `translateY(-3px)` + `--line-2` border. No card stays flat.
4. **Motion** — `--ease` spring, 150/280/450ms, interaction feedback ≤300ms.
   `transform` and `opacity` only. Never animate layout properties.
5. **Reduced motion** — honored globally in `tokens.css`. Any animation added
   must be disableable by that rule.
6. **Light mode parity** — every token has a light override. Verify both.
7. **Token-driven** — edit tokens, not rules.

## Accessibility

Semantic HTML first. Keyboard traversal of the entire reader. Focus rings
visible (`:focus-visible` is styled globally). Blocks carry `aria-label` from
their title. Progress bars expose `role="progressbar"` with values.

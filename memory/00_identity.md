# 00 · Identity

**The Money Map** — "Navigate Your Journey to Financial Freedom."

A local-first personal finance education platform. One Markdown source drives
the website, flipbook, PDF, and search index.

## What this is not

- Not a blog. Lessons are structured documents, not posts.
- Not an ebook viewer. The PDF is an output, not the product.
- Not financial advice. Every lesson preserves its source advisor disclaimer.

## The one principle

**Markdown is the source of truth.** Anything in `generated/` is disposable and
reproducible with `npm run generate`. If a fact exists only in a generated
artifact, that is a bug.

## Origin

Built from a 107-page infographic series (92 JPEG maps across 11 sections). The
infographics were the original product; here they are *extracted into structured
content* and retained as downloadable artifacts. See
`docs/superpowers/specs/2026-07-20-money-map-design.md` for why.

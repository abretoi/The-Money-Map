The map isolates one variable — return rate — while holding starting balance,
starting age, and contribution amount constant. That framing makes the
spread stark: the same saver, contributing the same $15,000 every year from
age 35, ends up anywhere from about $1.58M to about $3.84M by 65 depending
purely on which return path plays out.

The Rule of 72 panel translates the same idea into a more intuitive unit —
years to double — and shows why professionals talk about return rate in
terms of doubling time rather than raw percentage points.

The closing panel is the map's real argument: none of this requires predicting
which years will be good or bad. It requires showing up with the same
contribution, for three decades, and letting the return path do what it does.
